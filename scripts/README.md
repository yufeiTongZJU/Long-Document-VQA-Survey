# Rebuild the catalogs

Both scripts use Python 3.10+ and only the standard library.

## Render after editing committed JSON

For repository maintenance, edit the canonical catalog JSON and render its CSV and reading page without a manuscript checkout:

```sh
python scripts/render_catalog.py
python scripts/render_catalog.py --check
```

Use `--root /path/to/companion` for another repository location. The renderer preserves canonical JSON, checks citation keys, bibliography consistency, declared counts, group counts, and unique IDs/source orders, and regenerates the three CSV catalogs, three reading pages, and bibliography CSV. It updates artifact hashes in the manifest while preserving the original external `sources` hashes and the original import audit in `data/validation.json`.

When changing a count or group, update the corresponding JSON metadata. Bibliographic corrections must agree across `references.bib`, `data/bibliography.json`, and the affected catalog rows' copied bibliographic fields. Preserve citation keys and record IDs for existing records. Source-table names and line numbers describe the original import; document intentional departures from that snapshot in the pull request instead of claiming a new manuscript source.

## Import a manuscript snapshot

`build_catalog.py` imports an **external read-only manuscript** and replaces the canonical JSON as well as derived files. Use it only when deliberately importing a manuscript snapshot; do not run it to render repository JSON edits, because it would replace those edits with manuscript values.

```sh
python scripts/build_catalog.py --source /path/to/manuscript
python scripts/build_catalog.py --source /path/to/manuscript --check
python -m unittest discover -s scripts -v
```

On Windows, pass a quoted Windows path to `--source`. The default output is this repository. Use `--output /path/to/companion` to generate elsewhere. Source and output must be separate directories. `--check` validates input and compares every generated byte without writing.

Required external inputs:

- `tables/table4_full.tex` — 55 benchmark rows.
- `tables/table5_full.tex` — 29 methods without explicit retrieval.
- `tables/table6_full.tex` — 110 methods with explicit retrieval: 20 retrieval-only and 90 document VQA.
- `tables/table1_explicit_methods.tex` — source of the shared ordering convention, included in the source manifest.
- `references.bib` — 165 current entries, copied without modification.
- `reference_sources.json` — existing provenance used only for academic links; bibliographic fields are never imported from it.

The script writes three JSON catalogs, matching CSV files, three Markdown reading pages, a JSON/CSV bibliography, a sanitized root-level `reference_sources.json`, `data/validation.json`, `data/source_manifest.json`, and the byte-identical `references.bib`. The hand-written README files are not overwritten.

The conversion retains source order and exact text qualifiers, converts known LaTeX formatting to Unicode and explicit superscript notation, reads bibliography entries with balanced-brace parsing, and verifies that every table row has the expected columns and an existing citation key. Counts and group sizes are deliberate guards for this manuscript snapshot. When updating to a new snapshot, review changed counts, conventions, and new LaTeX commands before updating those guards.

The script does not query the web. It uses a conservative primary-publisher URL allowlist and explicit arXiv identifiers already present in source. Where no such destination is recorded, the reading pages clearly label the link **Google Scholar search**. Source provenance may predate the current bibliographic fields; only its recorded URLs are considered.

All generated outputs are deterministic for the same inputs. No timestamp or private source checkout path is included. The manifest hashes inputs and generated artifacts; it intentionally does not hash itself. Its `sources` section identifies the last imported manuscript snapshot, while `generated` hashes describe the current repository artifacts after rendering.
